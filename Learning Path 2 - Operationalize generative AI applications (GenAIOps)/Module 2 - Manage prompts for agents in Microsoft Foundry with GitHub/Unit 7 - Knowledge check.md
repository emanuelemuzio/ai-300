# Assessment

*1.* What happens when you create or update an agent in Microsoft Foundry?

> A new agent version is created automatically, whether you use the portal or the Python SDK.

*2.* In a proper prompt workflow, what should happen before a prompt change reaches production?

> Changes should be tested in development, validated in staging, reviewed by the team, and then deployed with monitoring.

*3.* What do Git tags provide for agent deployments?

> They create a traceable relationship between repository versions and deployed agents, simplifying debugging and rollback.
