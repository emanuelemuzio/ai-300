# Assessment

*1.* What is the main difference between monitoring and tracing in generative AI applications?

> Monitoring alerts you when something goes wrong, while tracing helps you understand what happened and where it happened.

*2.* In OpenTelemetry tracing, what represents a specific unit of work or operation within a trace?

> Span

*3.* Which Python packages are required to implement tracing in Microsoft Foundry applications?

> `azure-ai-projects`, `azure-monitor-opentelemetry`, and `opentelemetry-instrumentation-openai-v2`
