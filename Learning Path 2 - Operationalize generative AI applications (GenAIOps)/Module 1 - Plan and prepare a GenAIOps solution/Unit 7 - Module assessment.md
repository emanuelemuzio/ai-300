# Assessment

*1.* The Adventure Works team writes an agent specification before building. In it, they state that the agent must never invent discounts or give safety advice it can't ground in real data. Which part of the specification captures these rules?

> The restrictions within the agent's capabilities.

*2.* The Adventure Works product catalog changes constantly as items come and go, and the agent must always recommend products that are currently in stock. Which approach best fits this requirement?

> Retrieval Augmented Generation (RAG), so the agent searches the latest catalog data when answering.

*3.* In the GenAIOps lifecycle, which loop is where the Adventure Works team defines the business need and designs the agent's architecture, including prompts and models?

> The Explore loop.
