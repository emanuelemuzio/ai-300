# Assessment

*1.* What is the primary benefit of using shadow ratings during the transition from human to automated evaluations?

> Shadow ratings allow you to compare automated evaluator scores with human ratings to measure alignment before fully trusting automation.

*2.* When creating a synthetic test dataset, what percentage should typically represent edge cases?

> 5-10% to ensure the system handles unusual scenarios without over-optimizing for rare cases.

*3.* What triggers a GitHub Actions workflow for automated evaluation in a pull request-based workflow?

> Creating or updating a pull request that modifies prompt files.
